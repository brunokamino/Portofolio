Exemplo com dados fictícios

Estoque de exemplo por categoria

Escolha um lote de inventário para ver a última revisão de cada produto. O resumo conta produtos distintos e soma as unidades disponíveis por categoria.

—Registros de origem
—Produtos distintos
—Unidades em estoque
Estoque por categoria
CategoriaProdutosUnidades

Os registros de origem mostram o total do lote. O filtro de categoria é aplicado após selecionar a última revisão de cada produto.

Ver exemplo em T-SQL 
WITH UltimaRevisao AS (
  SELECT Produto, Categoria, Unidades,
         ROW_NUMBER() OVER (
           PARTITION BY Produto
           ORDER BY Revisao DESC, RegistroId DESC
         ) AS rn
  FROM dbo.InventarioExemplo
  WHERE Lote = @Lote
)
SELECT Categoria, COUNT(*) AS Produtos,
       SUM(Unidades) AS Unidades
FROM UltimaRevisao
WHERE rn = 1
  AND (@Categoria IS NULL OR Categoria = @Categoria)
GROUP BY Categoria;
Ver exportação em Python 
from pathlib import Path

import pandas as pd

# Resultado fictício da consulta para o Lote A.
resumo = pd.DataFrame({
    "Categoria": ["Papelaria", "Eletrônicos", "Acessórios"],
    "Produtos": [1, 2, 1],
    "Unidades": [24, 28, 17],
})

if resumo["Categoria"].duplicated().any():
    raise ValueError("Categoria duplicada no resumo")

resumo.to_excel(
    Path("inventario_exemplo.xlsx"),
    sheet_name="Resumo", index=False,
)
